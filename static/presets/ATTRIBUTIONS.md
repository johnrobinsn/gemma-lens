# Preset audio clip attributions

The four `.wav` files in this directory are derived from the ESC-50 dataset
(https://github.com/karolpiczak/ESC-50), which in turn derives them from
Freesound uploads. Original creator credits and licenses:

| File | Source clip | Freesound creator | License |
|---|---|---|---|
| `cow_moo.wav` | [TwoCows.wav](https://freesound.org/people/acclivity/sounds/16568/) | **acclivity** | CC BY-NC 3.0 |
| `cat_meow.wav` | [070422-cats-sample.wav](https://freesound.org/people/sazman/sounds/34094/) | **sazman** | CC BY 3.0 |
| `clapping.wav` | [Clapping Small Room.wav](https://freesound.org/people/sorohanro/sounds/104089/) | **sorohanro** | CC BY 3.0 |
| `rain.wav` | [unlocki door to mod rain.wav](https://freesound.org/people/cognito%20perceptu/sounds/17367/) | **cognito perceptu** | CC0 |

Three of the four clips (`cat_meow`, `clapping`, `rain`) are freely reusable with
attribution. **`cow_moo.wav` is CC BY-NC — non-commercial use only.** The
Gemma-Lens demo is a non-commercial research/educational project, which is
consistent with this license; if you fork this project for commercial use,
replace `cow_moo.wav` with a CC BY or CC0 cow clip from Freesound.

Full ESC-50 licensing details (all 2000 clips) live in the dataset repo's
`LICENSE` file: https://github.com/karolpiczak/ESC-50/blob/master/LICENSE
